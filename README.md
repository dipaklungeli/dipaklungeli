# Dipak Lungeli

**Assistive Technology · Screen Reader Development · Software Engineering**

Independent developer from Nepal focused on assistive technology and screen reader ecosystems. I build Lua extensions and utilities for Jieshuo+, Python add-ons for NVDA, and web and database applications, using AI-assisted workflows to research, prototype and refine my work.

| **AI Integration** | AI tools, APIs and development experiments |
